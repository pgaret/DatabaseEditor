F1 Manager 24's default game data (driver stats, retirements, calendar, everything) is one SQLite DB inside `F1Manager24/Content/Database/Volta.uasset` + `Volta.uexp`, packed in IoStore container `pakchunk0_s3-Windows.utoc/.ucas` (game at `C:\Program Files (x86)\Steam\steamapps\common\F1 Manager 2024`). Established 2026-08-23.

Key facts:
- AES key (reused from F1M23, verified via AESDumpster on the game exe): `0x43A5CEC244E89A3E109E14EDE787569E79C9CDECBB09857C6FEF080F14898EF9`
- `Volta.uexp` layout: 6-byte prefix, int32 LE payload size at offset 6, raw uncompressed SQLite from offset 10, then 4 zero bytes + UE package tag `C1 83 2A 9E`.
- Extraction: `retoc` (trumank/retoc) `to-legacy -f Volta <dir with global.utoc + pakchunk0_s3>` — needs `global.utoc` (in the Paks folder) staged alongside, or it fails with missing ScriptObjects chunk. retoc v0.1.5 crashes (generic-array panic) on the user's `RRacingV3_1_P.utoc` mod container but handles all base-game containers fine.
- `Content/Database/Diffs/Volta_XXXX_to_YYYY.uasset` are save-migration diffs between patch versions.
- Extracted DB: 317 tables, same schema as the save-embedded DB the DatabaseEditor project edits. Defaults only affect NEW careers; existing saves carry their own DB copy.
- Mods load as `<Name>_P` patch paks dropped into `F1Manager24\Content\Paks` (user already has RRacingV3 and extendedstandings UI mod installed). Repack route: retoc `to-zen`.
- Game UI is HTML/CSS (Coherent) — also moddable via pak overrides.

Working repack pipeline (verified 2026-08-23, byte-identical round trip):
1. Edit carved SQLite with sql.js — in-place UPDATEs keep file size identical, so splice bytes back into original Volta.uexp at offset 10 with no header patching.
2. `retoc to-zen --version UE5_1 <dir with F1Manager24/Content/Database/Volta.uasset+uexp> <out>\VoltaDefaults_1_P.utoc` (containers are UE5.1-era: TOC PerfectHashWithOverflow, header OptionalSegmentPackages). Output pak/ucas/utoc needs no encryption.
3. Drop the three files in the Paks folder. Installed mod: `VoltaDefaults_1_P` — applies repo's src/data/driver_stat_overrides.json (42 drivers, StatIDs 2-10 map in driverPresetUtils.js) + Vettel (StaffID 9) un-retired with RetirementAge 43.
Scripts live in session scratchpad (apply_overrides.js) — recreate from this memory if needed.

Lessons from testing (2026-08-23):
- retoc `to-zen` output _P paks CRASH the game on launch (regenerated zen package header rejected); UnrealReZen 1.0 can't parse the Volta asset either (packs empty). Working method: raw-chunk splice — `unpack-raw` pakchunk0_s3, splice same-size SQLite into chunk `4929639c00efdba200000001` at offset 247, `pack-raw`, replace pakchunk0_s3-Windows.ucas/.utoc in place (uncompressed+unencrypted replacement mounts fine; originals in `<game>\PakBackup`).
- The RRacing mod bundles its own full Volta DB and masks base-container edits; it's quarantined in PakBackup too.
- Portraits: face/body textures ship for many retired drivers (e.g. `UITextures/StaffPhotos/Faces/Named/Drivers/F1/S_Vettel_TN`) but the StaffID→texture map (`UITextures/StaffPhotos/StaffPhotoData.uasset`, uexp = 335 entries, 31-byte records, count@8, records from offset 12, key=StaffID int32) only covers active staff.
